## Lab Questions

### In plain English describe the function and use of a multiplexer.
The function of a multiplexer is to take multiple signals or inputs and output them into
single output thus combinging them. This can then also have the use take certain 
inputs only and combing those.

### In plain English describe the function and use of a demultiplexer.
The function of a demultiplexer is to take a single signal or input and output them into
multiple outputs. This can then also have the use of taking that input and only using 
certain outputs that are needed.

### What other uses might these circuits have? (Think Shannon’s)
They have uses in being applied in Shannon's Expansion since the theorem uses multiplexers
along with boolean functions. Where the boolean functions directly applied into the 
multiplexers.
